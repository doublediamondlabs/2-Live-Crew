2 LIVE CREW v0.3.2 — SIX NUTRIENTS, ONE SNACK BAG

UPDATE YOUR EXISTING APP
1. In Crew on each phone, use Setup > Export all races to keep a backup.
2. Extract this ZIP. Copy the CONTENTS of its 2-Live-Crew folder into your
   existing 2-Live-Crew repository folder. Replace matching source files.
   Keep the existing .git folder. Do not create another nested application folder.
3. In GitHub Desktop, review changes, commit and push. Wait for your existing
   GitHub Pages deployment to finish. Keep the published app URL unchanged.
4. Open the phone app while online; close/reopen or refresh until the footer or
   Setup shows Version 0.3.2. Do not clear app storage or uninstall to update.

WHAT CHANGED
Calories (kcal), carbs/protein/fat (g), sodium/caffeine (mg) now work throughout
food and recipe forms, label scanning/review, actual overrides, partial bottles,
per-stop totals and race totals. All values use the same numeric serving basis.
Serving description is optional reminder text, not an automatic unit conversion.

GOFER COMPANION EXPORT
Gofer > Food & fuel > Send to 2 Live Crew exports your saved foods and mixes.
Transfer the JSON by USB, email or another file service. In Crew, select the
race, then Setup > Defaults > Import from Gofer. Choose runner/items and review.
All six nutrients now feed Crew calculations. The existing Gofer exporter works;
its older on-screen note about three Crew totals describes the previous version.
Finished bottle volume is used for prepared recipes. Check bottle capacity.

EXISTING RECORDS
Older records remain as saved. Missing carbs/protein/fat stay Unknown, not zero.
For older imported defaults, open Original Gofer label & recipe and enter the
reviewed macro values into the editable nutrition fields on the same serving basis.
Editing a default does not alter prior stop entries or intake history.

Repeat imports still skip matching names. Rename a changed recipe in Gofer to
bring it in separately. Reviewed replacement imports are not included yet.
This release contains the previous companion importer. No Gofer app update is
required to export all six nutrients. Races and training plans do not transfer.

QUICK CHECK
Save a bottle with a 500 mL prepared volume and known nutrition values. Record
250 mL consumed and confirm each nutrient is half of the full-bottle amount.
Bottle capacity is not used to estimate consumption. Unknown values stay unknown.
